# Company profile: Halden Industrial (fictional)

Halden Industrial does not exist. It is a synthetic company used so that every solution in this repository works on the same data and the same assumptions.

| Item | Assumption |
|---|---|
| Employees | 5,000 |
| Plants | 12, in 3 regions |
| Revenue | EUR 1.2bn per year |
| Revenue per plant-day | EUR 400,000 (EUR 1.2bn / 12 plants / 250 working days) |
| Cost of one stopped line-hour | EUR 15,000 |
| Inventory | EUR 180M |
| IT tickets | 60,000 per year |
| Project portfolio | EUR 40M per year |
| Customer complaints | 1,200 per year |
| AI spend | EUR 3M per year |

These numbers are illustrative. They are chosen to be plausible for a mid-sized manufacturer and are not taken from any real company.
