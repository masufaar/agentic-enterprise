# Roadmap

## Done

- Ten solutions designed, each with a description and a one-page business case.
- Fictional company and shared assumptions defined.

## Next steps

1. Build the AI Governance Control Tower: registry, policy gateway, audit trail.
2. Build the synthetic data generator for the fictional company.
3. Build the first business solution on top of the Control Tower and register its agents.
4. Run the first red-team campaign and publish the results.
5. Connect both to the AI Value Ledger and publish the first board dashboard.
6. Add the remaining solutions one at a time, each as a thin working slice.

## Principles for the build

- One working slice per solution before any polish.
- No agent runs unregistered.
- Every claim in a business case is either measured in this repository or marked as an assumption.
